New in v1.7

每个角色，有自己的一页配置

宏不用堆在同一页，切换角色也不必重新勾选一键启动。

01

直接新建，随时改名

点击“新建”就得到空白的“配置 1、配置 2……”。可以重命名为角色或玩法，也可以删除不再使用的配置。

02

宏和一键启动各自保存

每个 Profile 有自己的宏、录制内容、一键启动快捷键和勾选项。不同 Profile 可以使用相同的宏名称和快捷键。

03

点击切换，自动保存

切换时保存当前编辑并应用目标配置，重启恢复上次选中项。切换会先停止宏并释放按键，回到游戏后再用快捷键启动。

浮层、窗口匹配和录制快捷键为公共设置。旧配置会自动迁移到“默认配置”；新建 Profile 从空白开始。

Features

减少长按和重复按键

按一次开启，再按一次关闭。按你的习惯配置动作与快捷键。

自动按住

最多设置 4 个按键槽位，同时按住其中所有非空按键，再按一次开关键全部释放。支持键盘和鼠标左键、右键、中键。

循环连按

按 4 个槽位的顺序循环短按并跳过空槽位。间隔默认 100ms，可手动调整，最低 1ms；实际时序受系统和游戏影响。

录制回放

在游戏内按 F12 开始倒计时，再按一次结束录制。支持执行一次或循环回放，记录鼠标点击落点，不录制移动轨迹。

一键启动

用一个快捷键控制选中的一组宏，可添加多组并单独启用。每个 Profile 独立保存这些组合，取消勾选也会正确保留。

游戏内状态浮层

显示当前 Profile 的宏名称、开关键、开关状态和录制进度。从游戏窗口左上方显示，鼠标穿透，接近时自动避让。

窗口限定与托盘运行

切出游戏会停止宏并释放输入，切回后不会自动恢复。配置好后可隐藏到托盘，退出时清理按住的鼠标和键盘状态。

Screenshots

公共设置在外，角色配置在内

Profile 中只保留宏配置和一键启动；内容较多时可以滚动，公共设置、支持入口和保存按钮保持可见。

Quick start

从默认配置开始，再为角色建一页

  1. 1

    解压并运行

    解压下载包，运行 D4Helper.exe。默认已匹配暗黑 4；需要调整时打开“高级设置 → 窗口匹配”。

  2. 2

    准备角色 Profile

    可以直接试用“默认配置”，或点击“新建”创建空白页，再用“重命名”改成自己的角色或玩法。

  3. 3

    设置宏和一键启动

    添加宏并选择动作、槽位和间隔。点“录”绑定按键，点“选”选择常用键；在“一键启动”中勾选要控制的宏。

  4. 4

    保存并回到游戏

    点击“保存并应用”，回到暗黑 4 使用快捷键。以后点击标签切换整套配置，切换时会自动保存当前编辑。

默认配置快捷键

  • F1交互，每 100ms 短按 F
  • F2右键连点，间隔 100ms
  • F3旋风斩，自动按住右键
  • F4增益技能，循环 2 → 1 → 3 → 4
  • F5大招，每 1000ms 短按左键
  • 鼠标中键一键开关 F1、F3、F4、F5 对应的宏
  • F12开始或结束游戏内录制

使用前了解

  • 已有配置默认按键仅适用于初始配置，你已有的设置会保留。
  • 切换配置只切换设置，宏需要通过快捷键重新启动。
  • 录制内容保存到录制时的 Profile，新增录制宏需要手动勾选启用。
  • 鼠标避让默认 72 像素，可调整为 16–400 像素或关闭。
  • 输入间隔原生输入内核支持最低 1ms 的调度目标，建议先从 100ms 试用。
  • 运行权限游戏以管理员权限运行时，D4Helper 也需要相同权限。

Release notes

这两个版本，改了什么

v1.7.0 本次更新

加入角色 Profile

独立保存宏和一键启动，切换自动保存，重启恢复选中项。公共设置移出标签内容，长列表支持滚动；修复一键启动勾选恢复的问题。

v1.6.0

精简界面，更新输入内核

移除路线地图、浮层拖动和布局编辑快捷键，F10、F11 可自由绑定宏。加入原生高精度输入内核和鼠标避让，状态浮层从游戏窗口左上方显示。
