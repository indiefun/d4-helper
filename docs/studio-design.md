# Studio 交互设计

Studio 的唯一核心对象是“宏”：一段有长度的时间轴，里面有多条轨道。一个快捷键播放整个宏。

## 从用户任务开始

用户想表达的是“从这个时间开始按住右键，同时在后面几个时间点击技能”，而不是“创建四槽循环，再建立一个组合开关”。因此：

- 横向统一表示时间，纵向只是整理动作。
- 一个动作块表达一个输入意图。
- 块的位置决定何时开始，宽度决定持续多久。
- 空白表示等待，不另外配置等待动作。
- 所有轨道共用一次播放、一个循环、一个快捷键。
- 新建宏默认只有一条轨道，需要时再添加，已有宏的轨道布局保持原样。
- 点击和按住块根据时长自动完成按下与释放，不提供独立按下 / 抬起动作。

## 界面区域

| 区域 | 用户能做什么 |
|---|---|
| 左侧我的宏 | 选择作品、新建；数量与长度摘要 |
| 动作积木栏 | 拖入点击、按住、鼠标移动和滚轮 |
| 中间时间轴 | 跨轨拖动、拉伸、吸附、缩放、静音、预览 |
| 右侧属性 | 随选择切换：选中宏时显示宏属性，选中动作块时只显示该动作的属性 |
| 上方播放区 | 选择目标窗口、录制、停止、真实运行 |
| 底部预览区 | 快速查看动作先后，显示动作校验错误 |

设置窗口只放窗口匹配、录制与紧急停止等全局选项。常规编辑无需打开高级表单。

宏属性集中编辑名称、快捷键、是否允许快捷键启动、循环和时间轴总长。时间轴顶部与底部只显示播放方式及总长。动作属性只编辑该动作的按键、开始、时长、位置等，不混放宏设置。单个点击块只表示一次点击；重复动作通过复制块明确展示，整体重复由宏的循环控制。

## 关键交互规则

1. 拖动作到轨道时，鼠标横坐标就是开始时间；默认 10ms 吸附，可关闭后按 1ms 编辑。
2. 点击积木时，在当前选中轨道、播放头位置添加。
3. 跨轨移动不改变动作类型；轨道没有强制的键盘 / 鼠标类别。
4. 同一轨道可以重叠，画面自动错行。不同轨道自然并行。
5. 细短动作按真实时长画出，旁边显示名称；放大后可以更精细地拖拽，右侧数值始终可精确输入。
6. 拉伸录制鼠标轨迹时，所有轨迹点按比例缩放。
7. 每个点击或按住块自动产生完整的按键动作，静音轨道无需考虑其他轨道的按键配对。
8. 重叠的同键长按按所有权合并，直到最后一个块结束才抬起。
9. 多段平滑鼠标移动不能互相重叠，因为系统只有一个鼠标指针；保存时指出冲突。
10. 本地预览不发送输入。真实运行需切回指定窗口，切出立即停止。

## 新数据模型

```text
Workspace（窗口与录制设置）
 └─ Macro（快捷键、循环、总长）
     ├─ Track（名称、静音）
     │   ├─ Block（点击，开始 200ms，持续 60ms，键 2）
     │   └─ Block（点击，开始 800ms，持续 60ms，键 1）
     └─ Track
         └─ Block（按住，开始 200ms，持续 1200ms，右键）
```

轨道与动作块只存在于编辑层。编译结果是按绝对时间排序的原始事件，含按键、鼠标移动与滚轮。引擎不解释轨道、槽位、动作模式或组合开关。

## 本轮没有扩展的复杂度

没有引入节点连线、脚本语言、条件分支或嵌套流程；没有多套“简单 / 高级 / 录制”编辑器。所有创建方式最终都回到同一根时间轴。多选批量移动、框选、片段分组、窗口相对坐标可以后续加入，不影响当前模型。

旧版配置不自动迁移；旧工具保留作为独立回退。这样新用户无需理解旧版概念。
