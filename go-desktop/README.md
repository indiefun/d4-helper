# D4Helper · 节点工作台

Go 执行内核保持独立，配置界面使用节点图。分支为 `feat/node-workflow-editor`；当前版本 `3.0.0-alpha.2`。设计和交互说明见 [NODE-EDITOR.md](NODE-EDITOR.md)。

## 使用

从开始节点设置快捷键，点击左侧动作追加节点。动作完成后沿连线继续，等待使用单独节点。按键与时长在节点卡片内修改。并行节点同时启动多个分支，汇合节点等所有输入完成后继续。整个流程循环在开始节点或右侧流程设置中开启，并可设置每轮等待。

滚轮缩放、拖动空白平移、双击空白搜索添加；支持拖入节点、拖线连接、断线、节点复制、删除、撤销重做、自动整理和缩略图。底部预览只高亮步骤，不发送真实输入。未连接开始的节点保留在文件中，但不执行。

点击保存后切回目标游戏，使用快捷键运行。切出游戏停止并释放输入，紧急停止键默认 Pause。窗口设置、录制、按键录入、屏幕取点和托盘继续使用 Go 桥接接口。

## 文件兼容与编译

使用 `workspace.timeline.json`，仍为 schema 3；节点宏增加 `graph.version = 1`。图是执行依据，Go 重新计算派生轨道，文件提供的轨道缓存不能覆盖图。连线决定顺序，布局不影响时间；汇合取全部输入的最晚结束时间，末尾等待计入单次时长。拒绝环路、无效连线、超过 1 小时或超过事件/并发上限的流程。

旧时间轴文件打开后在内存中转换成节点：各轨道为并行分支，空白变成等待；保留时间、录制轨迹、关闭状态和宏循环。保存前不修改源文件。保存后的节点作品应在本分支编辑，旧工作台无法编辑节点图。

```text
frontend/graph-model.js + app.js    节点、连线、布局、预览、撤销
                  ↓ graph.version 1
internal/timeline/graph.go         依赖排序、汇合、时间计算、轨道生成
                  ↓
internal/timeline/compile.go       动作校验、移动采样、事件合并
                  ↓ sequence.Plan
internal/engine                   高精度调度、输入所有权、录制、失焦释放
                  ↓
internal/win                      SendInput、窗口、托盘、浮层
```

事件内核不持有节点或 UI 状态。无活动宏时无限等待；同键重叠使用引用计数，最后一个所有者退出才释放。平滑移动采样间隔不超过约 8ms；明显延迟时平移剩余事件，避免把按住时长压成瞬间输入。

## 打包与验证

从仓库根目录运行 `./build.ps1`。Go 发布只放在 `dist/go/`：`D4Helper.exe`、`workspace.timeline.json`、`VERSION`、`D4Helper-Studio.zip`。覆盖程序和固定名称压缩包，保留本机已有工作区；压缩包只使用源码生成的默认配置。构建脚本按绝对路径关闭占用文件的本仓库 Go 程序。旧 Python 版保留在 `dist/` 根目录。详见根目录 `AGENTS.md`。

在 `go-desktop/` 中运行：

```powershell
go test ./...
go vet ./...
npm test
npm run test:browser
./tools/smoke.ps1 -Binary ../dist/go/D4Helper.exe
```

Go 测试覆盖图的并行汇合、尾部等待、循环、错误连接、轨道缓存重建和原有输入内核。前端测试覆盖编辑、时间重算、撤销、保存重开、节点复制及旧配置转换。浏览器测试通过独立的无头 Edge 验证真实拖线、节点拖动、缩放平移、预览和 1200px 布局；截图在 `build/`。桌面自检强制 dry-run，验证真实 WebView 与 Go 桥接。

## 试用范围

Windows amd64。支持顺序、等待、并行、汇合和整段循环；条件判断、局部循环、子流程、多选暂未实现。鼠标使用绝对屏幕坐标。无输入自检不代表实际游戏输入识别率。最初的 Go/C++ 计时实验仍在 `results/`。
