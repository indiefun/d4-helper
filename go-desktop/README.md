# D4Helper · 节点工作台

`3.0.0-alpha.3`，分支 `feat/node-workflow-editor`。第二版已接入实际 Go 执行程序：独立抽屉、五种动作、可嵌套的同时执行与有限重复范围。

## 使用

左侧「宏」和「节点」分别打开独立抽屉，再点收起。节点库只有点击、按住、等待、移动、滚轮五种动作；按键、时长、录入、坐标和屏幕取点均在卡片上。卡片中间的「＋」插入动作，也可以从节点库拖入指定分支。常驻右侧属性面板已移除。

选中动作点「同时执行」建立分支，所有分支同时开始，全部完成后继续。选中同一顺序内的连续内容，点「重复这一段」，设置 1–100 次和两轮间隔。重复范围可包住整个并行框，分支内也可包含重复框。两轮间隔只发生在相邻轮之间，最后一轮后直接继续。顶部「整个宏」控制持续循环和每轮间隔。

Shift 点选或 Shift 拖动框选连续内容；支持分支增删、折叠、动作拖放重排、复制、停用、删除、撤销重做、缩放和平移。底部预览只高亮动作，不发送按键，可展开执行明细。宏设置可以重命名、复制、删除、启用和设置快捷键。

编辑后保存，回到目标游戏按快捷键执行。顶部「运行宏」给 2 秒切换窗口时间。切出目标窗口停止并释放输入，Pause 默认紧急停止。窗口设置、游戏浮层、录制、取点和托盘使用原有 Go 桥接。录制产生的轨迹会保留采集点，修改轨迹时长同步调整点位时间。

## 文件与兼容

使用 `workspace.timeline.json` / schema 3，新版宏为 `graph.version = 2`，内部保存 sequence、parallel、repeat 和动作结构。Go 在加载、保存或应用时将结构编译为事件计划，运行线程不解释编辑器结构。有限重复在展开前检查次数、深度、时长和事件预算。结构宏不持久化展开轨道缓存，避免重复动作放大文件体积。

旧时间轴和 graph v1 在前端内存中按原绝对时间转换为带等待的并行分支，保存前不改写原文件。原始 graph v1 另外保留为 `source_v1`，含未连接草稿和原布局；当前编辑的是具有相同执行时序的结构版本，编辑前序动作后，后续时间随顺序关系重新计算。轨迹、关闭状态、末尾等待、整宏循环保留。旧版程序不支持 graph v2，请使用此分支继续编辑新版宏。

```text
frontend/flow-model.js + app.js     抽屉、动作、范围、选择、预览、录制导入
                  ↓ graph.version 2
internal/timeline/flow.go          范围计时、预算检查、有限重复展开
                  ↓ 派生轨道
internal/timeline/compile.go       键鼠校验、移动采样、事件合并
                  ↓ sequence.Plan
internal/engine                   截止时间调度、输入所有权、录制、失焦释放
                  ↓
internal/win                      SendInput、窗口、托盘、浮层
```

## 打包与验证

根目录运行 `./build.ps1`。发布仅放在 `dist/go/`：程序、工作区、VERSION、固定名称 `D4Helper-Studio.zip`。保留已有工作区；压缩包使用源码生成的默认示例。原 Python 版保留在 `dist/` 根目录。详见根目录 `AGENTS.md`。

在 `go-desktop/` 运行：

```powershell
go test ./...
go vet ./...
npm test
npm run test:browser
go run ./tools/verify-flow-workspaces.go ./build/browser-flow-workspace.json ./build/flow-migration-cases.json
./tools/smoke.ps1 -Binary ../dist/go/D4Helper.exe
```

Go 验证范围计时、重复预算、嵌套、录制轨迹、输入计划执行、失焦释放和保存重开。前端单元测试覆盖 Go 保存/运行接口、后端拒绝时不执行、迁移、参数回滚和录制导入；独立无头 Edge 验证真实框选、拖放、插入、抽屉、预览及 1200/1600px 布局。迁移工具对比转换前后的完整 Go 事件计划。截图和报告在 `build/`。桌面 smoke 强制 dry-run，检查实际 WebView 和 Go 桥接。

## 范围

Windows amd64，鼠标为绝对屏幕坐标；最多 64 条并行分支、32 层结构、4096 个结构节点、1 小时、100000 个展开动作/事件。不同分支的重叠鼠标移动仍拒绝。支持局部有限重复与整个宏持续循环；条件判断、可复用子流程和自由 DAG 编辑尚未提供。实际游戏识别率需要用真实用例验证。

设计来源和原型见 [NODE-EDITOR-V2.md](NODE-EDITOR-V2.md)。
