# 节点编辑器试用版

分支：`feat/node-workflow-editor`。

节点从左向右阅读，连线表示“上一步结束后执行”。位置只影响布局，不改变时间。点击左侧节点即可接在选中节点后面，也可以从输出圆点拖到输入圆点连接。开始节点设置快捷键和整段流程循环；等待使用独立节点。并行节点同时启动各分支，汇合节点等待全部输入结束。循环不通过回连表示，避免误连导致无限执行。

按键和时长在卡片内修改。滚轮缩放，空白处拖动画布，双击空白搜索添加节点；支持删除连线、节点复制、撤销、自动整理和适应画布。未连接开始的节点保留在作品内，但不参与执行。预览仅高亮流程，不发送键鼠输入。

保存仍使用 `workspace.timeline.json` / schema 3，宏增加 `graph.version = 1`。图是执行依据，Go 编译器重新生成派生轨道，再交给原有事件编译与调度内核。末尾等待参与实际时长，汇合取最晚分支结束时间，环路及错误端口连接会被拒绝。

已有时间轴作品首次打开时在内存中转换：各轨道变成并行分支，空白转成等待，录制轨迹和关闭状态保留；保存前不改写原文件。旧工作台无法编辑节点图，建议在此分支继续编辑保存过的节点作品。

本版提供顺序、并行、汇合与整段循环；条件判断、局部循环、可复用子流程暂未实现。
